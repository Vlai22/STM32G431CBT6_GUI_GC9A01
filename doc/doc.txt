PB11 - RESET экрана для активации в нужный момент 
PB14 - A0 управления что должно поступать на экран команда или данные что бы освободить PB14 и можно было к spi подключить доп чипы
 - включения подсветки в даном случае не подключен нужено распаять транзистор для управления 
PA5 - SPI1_SCK для флешки 
PA6 - SPI1_MISO для флешки 
PA7 - SPI1_MOSI для флешки 
PA4 - выбор флешки для общения
PA0 - A энкодера
PA1 - B энкодера
PA2 - В режиме сна отключение перефери для экономии батареи
PA11 - usb_dm
PA12 - usb_dp
PB6 - UCPD1_CC1 
PB4 - UCPD1_CC2
PB8 - I2C1_SCL 
PB9 - I2C1_SDA
PA8 - FOC TIM1_CH1 A 
PA9 - FOC TIM1_CH2 B 
PA10 - FOC TIM1_CH3 C
PB0 - FOC Analog in1 AD.C12
PB1 - FOC Analog in2 ADC12 
PB2 - FOC Analog in 3 ADC2
PB7 - FOC enable
PB10 - INPUT Alert BMS 
PA3 - кнопка запуска старта вентилятора 
PA3 - кнопка круилки оборотов вверх 
PA3 - кнопка крутилки оборотов вниз 
PA3 -  дополнительная кнопка управления 
PC14 - кварц часовой
PC15 - кварц часовой
PF0 - кварц освновной 8 мгц
PF1 - кварц основной 8 мгц
PB5 - светодиоды индикации ws2812B 
В данном проекте используеться следующая связка микросхем:
STM32G431CBT6 - микроконтроллер 
S25FL256LAGNFN013 - микросхема flash памяти 32 мб QSPI
AT24C02 - EEPROM I2C
MP2307DN - dc-dc понижающий 
XC6206P332MR - линейный понижающий преобразователь 
Круглый дисплей IPS GC9A01 SPI 
SC8815QDER - контроллер зарядки Buck-Boost с управление i2c 
BQ7692006PWR - контроллер бмс i2c 
DRV8823HRTAR - трехфазный драйвер мотора 
MT6701CT-STD-R - энкодер магнитный SPI 
Этапы разаботки, в первую очередь по скольку есть экран нужно разобраться с графикой, затем  можно перейти к алгоритму
 FOC поскльку есть логический анализатор и можно эмулировать положение энкодера одновременно с чередованием фаз 
 затем уже перейти к работе с памятью, микросхемами бмс, зарядки, bootloader.
Описание проекта полное задумки:
Вентилятор с  bldc мотором и круглым экраном управления, для гиков есть возможность кастомизированния интерфейса, создания профилей,
вывода инфографики, также для более закрытых производителей есть возможность перехода на более дорогую микросхему 
бмс и соответсвенно индивидуальный закрытый аккамулятор. Гаджет имеет как и все современные устройства возможность быстрой зарядки,
а также как полноценное заводское устройство собственное приложение на пк и свой usb драйвер. Также обновление прошивки через usb для 
поддержки долгое время без изменения железа.
